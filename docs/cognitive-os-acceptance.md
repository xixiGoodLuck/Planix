# Pure Planix V2 Planning Runtime acceptance

This document is an alias for the current formal acceptance contract. The executable source of truth is `docs/cognitive-planning-acceptance.md`.

Acceptance requires one native runtime and graph, direct `PlanBlueprint` generation, deterministic and semantic quality gates without a numeric threshold, bounded issue-scoped repair, validated Schedule and Calendar proposal, version-bound Final Approval, explicit Calendar permission, Artifact-only planning bodies, fail-closed model recovery, and non-destructive archival of retired Sessions.
